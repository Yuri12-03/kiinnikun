# 時間指定と種目説明の検証

日付：2026-11-27。バージョン：1.0.2 / Android versionCode 3。

## 仕様

- 条件入力画面に10〜60分、5分刻み、初期値30分のスライダーを追加。
- 選択時間をAIに渡し、メニューと差し替え後の全体の概算時間が選択時間以内であることを検証。
- 既存の時間計算を使用：1種目あたり `セット数×回数×4秒×左右係数＋(セット数−1)×休憩秒＋60秒`。左右係数は片側種目のみ2。
- 準備運動・着替えは概算に含めない。無理に運動量を増やして時間を埋めないため、選択時間より短い結果を許容。
- 旧APKは時間を送らないため、時間省略時には従来の処理を維持。
- 全27種目に2手順とコツを用意し、通常カードと代替候補に共通コンポーネントで表示。AI生成の説明ではないため、追加のAPI利用なし。

## 確認結果

- 型チェック・lint：成功。
- 自動テスト37件：成功。時間の範囲・型・刻み、上下限と超過、左右別の概算、差し替え時の時間引き継ぎ、旧リクエストとの互換性、全種目のガイド網羅を確認。
- Android・iOS・Webのバンドル出力：成功。Web専用のアクセシブルなrange入力は、ブラウザで別途確認。
- `generate-menu` / `replace-exercise`をSupabaseへデプロイ済み。
- 実際のGemini（脚・ジムあり）：10分指定は4種目・概算10分、30分指定は4種目・概算17分。短い指定では一部が1セット、長い指定では全種目2セットとなり、時間が反映されることを確認。確認用一時セッションは終了時にログアウト。
- ブラウザ：クリックによる変更、矢印キーの5分刻み、10分・60分での上下限制御、表示値と読み上げ値の一致を確認。
- Android実機でのスワイプ操作と上書きインストール後の確認は別途必要。
