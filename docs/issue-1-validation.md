## Android接続の調整

- Expo Goで`java.io.IOException: Failed to download remote update`が発生したとの報告。
- LANの開発サーバーは稼働し、Android用接続情報のWi-Fiアドレスも正しいことを確認。
- `@expo/ngrok`を開発依存に追加し、`npm run start:tunnel`でngrok方式のトンネルを起動できるようにした。
- トンネル経由で接続情報とAndroidバンドル（HTTP 200、6,803,306 bytes）を取得できることを確認。
- 新しいトンネル用QRを使用し、AndroidのExpo Goでアプリが開いたことを利用者が確認（2026-11-24）。LAN経路の制限が疑われるが、ルーターや端末のどの設定が原因かまでは特定していない。
- 端末名・OSバージョンと、スマホ画面でのログイン・メニュー提案操作は未確認。
- その後、利用者から「スマホでは問題なく動いた」と報告があり、Android実機での主要機能確認を完了扱いとした。利用者の指示によりGitHub Issue #1をcompletedでクローズした。
