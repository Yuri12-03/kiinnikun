# 部位カード内のおすすめマーク

2026-11-27 / バージョン1.0.4、Android versionCode 5。

## 変更

- 独立したおすすめカードを削除し、既存の6部位カードに「おすすめ」バッジを表示。
- おすすめの判定には既存の履歴取得・48時間の除外・記録なし優先・古い順の最大2部位を使用。
- 部位カードを共通コンポーネントにし、従来のタップによる選択・解除を継続。
- 選択中の深緑背景でもバッジが読めるよう、バッジは淡い背景と深緑の文字に統一。
- 読み上げ用ヒントにおすすめであることと理由を設定。
- 読み込み中・失敗時・候補なしの案内はカード一覧の下のテキストで表示。失敗時は再読み込み可能。
